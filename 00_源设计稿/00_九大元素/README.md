# 世界观文档分层与维护入口（2026-04-18）

## 目标

- 为 `10_worldbuilding` 提供唯一导航入口。
- 明确“主档 / 附录 / 归档”层级，减少平行口径与重复维护。

## 分层定义

- 主档：可被章节写作直接调用的权威正文，持续更新。
- 附录：结构化补充材料，服务主档，不单独形成口径。
- 归档：历史记录或迁移说明，只追溯不维护。

- 不保留独立归档文件；历史版本统一使用 Git 历史追溯。
- 已收敛文档内容已并入主档或治理总纲。

## 维护规则

1. 新增内容先判断是否能并入现有 `元素-*.md`。
2. 无法直接并入时，先放入附录层，完成校验后再并入主档。
3. 禁止新增“平行主档”或“同主题第二份总表”。
4. 引用路径优先指向 A 层主档，不引用临时稿路径。

## 变更流程

1. 修改 `00_source/元素设计/*.xmind` 设计源。
2. 同步更新本目录对应 `元素-*.md` 主档。
3. 在需要的章节或索引文件中仅写调用说明，不复制主档正文。
