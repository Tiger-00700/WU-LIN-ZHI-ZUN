## 二、核心关系链

### 师徒链（含三圣传承）

```
大悲老人（刀圣，隐世兜底）
│
├── 武绝盛（弟子，第一刀）
│   │
│   ├── 张天风（刀法继承→剑法自创）
│   ├── 武庚（刀法继承，第二部由大悲亲自带）
│   └── 大悲将沧浪剑交给天风——剑圣的剑，刀圣代管
│
├── 剑圣·谢青峰（未出场，通过沧浪剑封蜡"谢"字暗示）
│
└── 枪圣·陆沉渊（未出场，通过路远行→赵信陵传承链条暗示）
```

### 结拜/兄弟链（E线核心）

```
第一阶段：ch005 初遇留印
天风 ↔ 天鸣：「这人拳路不错。」「这把刀稳。」

第二阶段：ch006 出手相助
天鸣 → 天风：挡落下的横梁，点头示意

第三阶段：ch017 雪中重逢 → 结拜
天风：「你帮我挡过那根横梁，我记得。」
天鸣：「你的刀路我也记得。」
两人在雪地对了一掌，结拜——白雪印证坦诚。

第四阶段：ch023 断碑结盟
情感结拜 → 行动同盟
五人（天风、天鸣、武庚、文君、顾清樽）共立断碑前

第五阶段：ch036 五人歃血盟
天风、天鸣、武庚、文君、小七

第六阶段：ch037 身份暴露
天鸣：「你是我兄弟，但我爹是你杀父仇人。」
武庚拔刀指向天鸣，但最终没有砍下去。
```

### 感情链

```
武绝盛（养父）
│
├── 张天风（养子）← 武灵（暗恋）
│   │
│   └── 与独孤文君相恋（ch005互生好感 → ch037被迫分离 → ch040文君被俘西去）

├── 武灵（亲女）→ ch043青丝变白丝，白衣入谷隐退
│
└── 武庚（亲子）
    │
    └── 与天风是兄弟 + 与天鸣是仇家之子
```

### 敌对链（第一部逐步形成）

```
武圣庄 ←→ 魔教（全面敌对）
│
├── 武绝盛 ←→ 独孤残（ch033同归于尽）
├── 张天风 ←→ 铁风（ch026斩杀，为冯六报仇）
├── 武庚 ←→ 天鸣（ch037身份暴露后，武庚开始敌视）
└── 张天风 ←→ 殷绝尘（ch034顾清樽指出后，天风开始追查）

魔教内部：
忠心派 ←→ 野心派（殷绝尘清洗忠心派，内斗不止）
```
